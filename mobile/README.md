10k-SCS Project — Mobile Prototype

This folder contains a minimal Expo app to prototype the React Native migration.

Usage

1. From this repo root, switch to the `mobile` branch (already on it):

```bash
cd mobile
npx expo start
```

2. Install dependencies when prompted by `expo`.

Notes
- This is a shallow scaffold for rapid iteration. We'll copy shared logic into `packages/shared` or `mobile/src/shared` next.
